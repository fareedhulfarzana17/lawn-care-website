# Lawn Care Website

A responsive lawn care service website built using HTML, CSS, and JavaScript.

## About the Project

This project is a front-end website designed for a lawn care service business. It includes multiple sections such as services, seasonal lawn care tips, testimonials, blogs, contact information, and a newsletter subscription.

## Features

- Responsive website layout
- Mobile navigation menu


## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## What I Practiced

- Structuring webpages using semantic HTML
- Responsive web design
- CSS layouts and styling
- Creating a mobile navigation menu with JavaScript
- Working with external fonts and icon libraries
